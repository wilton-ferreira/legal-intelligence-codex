# Legal Intelligence · Brasil

Leia [contexto brasileiro](../../references/direito-brasileiro.md).

Use o contexto existente e faça somente perguntas que mudem a entrega. Não imponha formulário inicial. Escolha uma habilidade e execute na mesma tarefa, lendo somente os recursos necessários:

| Pedido | Habilidade |
|---|---|
| Iniciar análise e organização de um caso | [landin-iniciar-processo](../landin-iniciar-processo/SKILL.md) |
| Revisar processos e produzir versões melhoradas em uma pasta | [landin-revisar-processos](../landin-revisar-processos/SKILL.md) |
| Leis, jurisprudência e fundamentos de tese | [pesquisar-direito-brasileiro](../pesquisar-direito-brasileiro/SKILL.md) |
| Conferir citações | [verificar-citacoes](../verificar-citacoes/SKILL.md) |
| Entender autos | [triagem-de-autos](../triagem-de-autos/SKILL.md) |
| Rever contrato | [revisar-contrato](../revisar-contrato/SKILL.md) |
| Comparar riscos | [matriz-de-risco](../matriz-de-risco/SKILL.md) |
| Redigir minuta | [redigir-documento-juridico](../redigir-documento-juridico/SKILL.md) |
| Reduzir identificadores | [anonimizar](../anonimizar/SKILL.md) |
| Auditar integridade | [auditar-peca](../auditar-peca/SKILL.md) |
| Consultar publicações DJEN | [consultar-comunicacoes](../consultar-comunicacoes/SKILL.md) |

Não acione todas as habilidades ou crie agentes/tarefas automaticamente. Para apresentar o plugin, ofereça três exemplos adaptados ao usuário. Não prometa acesso a autos restritos, memória de casos ou monitoramento automático.

Para os rituais especializados do escritório (recurso inominado, laudo, BPC,
audiência e contestação), consulte o [mapa Landin](../../docs/landin-incorporacao.md)
e carregue apenas o fluxo pertinente.
